# Kyro Assistant

Android Studio starter for a personal voice assistant named Kyro.

## Current features
- Voice recognition using Android speech recognition
- "open YouTube" / "open <app>" app launching
- "call <number>" calling flow with permission handling
- Android Settings shortcut
- Simple Kyro interface

## Next production stages
- "Hey Kyro" wake-word activation
- Natural-language command router
- Foreground service for background operation
- Reminders, alarms, media controls and more Android intents
- Accessibility actions where Android permits them
- Optional AI backend for conversational responses

Kyro must respect Android permissions and device security; it should not bypass a lock screen or other security controls.
